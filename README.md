# Flowerbed

## Setup

Flowerbed uses git submodules in order to modify submissions to Mod Garden: DIY.

```shell
git clone https://github.com/ModGardenEvent/flowerbed.git
git switch diy
git submodule update --init --recursive
```

For further setup instructions please see the [fabric documentation page](https://docs.fabricmc.net/develop/getting-started/setting-up-a-development-environment) that relates to the IDE that you are using.
